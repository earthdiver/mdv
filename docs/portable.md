# ポータブル版

配布に必要なのは `MDV.exe` 一つです。.NETとWebView2 Fixed Version Runtime、描画ライブラリ、サンプル、説明書、ライセンスを内蔵しています。インストーラーや管理者権限、実行先でのランタイム導入は不要です。USBメモリーなどから利用する場合も、EXEを置くフォルダへの書き込み権限が必要です。

## 設定

初回起動時にEXEと同じフォルダへ `MDV.ini` を作り、終了時に変更した設定を保存します。文字コードはUTF-8です。カレントディレクトリやショートカットの「作業フォルダー」には依存しません。

```ini
; MDV portable settings — UTF-8
[Viewer]
Mode=github
Theme=light
Zoom=1
ShowSource=false
ShowOutline=true
AllowRemoteImages=false

[RecentFiles]
File1="C:\Documents\サンプル.md"
```

| キー | 値 |
| --- | --- |
| `Mode` | `github` / `qiita` |
| `Theme` | `light` / `dark` |
| `Zoom` | `0.5`〜`2.5`。小数点は `.` |
| `ShowSource` | ソース欄の表示。`true` / `false` |
| `ShowOutline` | 目次の表示。`true` / `false` |
| `AllowRemoteImages` | 外部画像の取得。`true` / `false` |
| `File1`〜`File12` | 最近開いたファイルの絶対パス。最新が `File1` |

INIを手動編集する場合はアプリを終了してください。セクション・キーの大文字小文字は区別せず、未指定・無効な値は既定値へ戻します。拡大率は範囲内に補正します。`;` / `#` で始まる行はコメントです。保存時に全体を書き直すため、コメントや未定義のキーは保持しません。

EXEとINIを一緒に移動すると設定を引き継げます。EXEを `Reader.exe` に改名した場合はINIも `Reader.ini` に改名してください。最近開いたファイルは絶対パスなので、別のPCや異なるドライブ文字への移動で文書の場所が変わった場合は、開き直してください。

INIに書き込めない場合はエラーを表示します。AppDataやレジストリへの保存に切り替えることはありません。以前のバージョンが作成した `%LOCALAPPDATA%\MDV\settings.json` は読み書き・自動移行しません。

## 一時ファイル

単一EXEは**配布形式**です。WebView2や.NETのネイティブライブラリは起動時にディスクへ展開して実行します。

EXE内の.NETアセンブリには単一ファイル圧縮を適用しており、起動時にメモリ上へ展開します。内蔵資材はTARにまとめてBrotli（品質9）で圧縮しています。これはファイル間の重複も圧縮できる形式です。資材を展開するときはストリームで各ファイルへ書き込み、中間の未圧縮TARや、資材全体を保持するための追加のメモリ領域は作りません。

WebView2の実行ファイル・DLLはディスク上に必要なため、全体をメモリだけで実行する方式ではありません。配布EXEの小型化と、次回起動時の展開済みキャッシュ再利用を両立させています。

| 場所 | 内容・寿命 |
| --- | --- |
| EXEと同じフォルダの同名 `.ini` | ユーザー設定・最近開いたファイル。持ち運ぶ設定はこのファイルだけ |
| `%TEMP%\MDV\payload\<SHA-256>` | 同梱ランタイム・描画資材・ライセンス。再起動を速くするため再利用 |
| `%TEMP%\MDV\sessions\<起動ごとのID>` | WebView2の作業データ。正常終了時に削除 |
| `%TEMP%\.net\<EXE名>\…` | .NETが展開するネイティブライブラリ。ランタイムが管理 |

初回起動には展開用の空き領域が必要です。EXEは数百MB、展開資材は約700MBになるため、一時フォルダには1GB以上の余裕を用意してください。複数バージョンを使うと資材のキャッシュも増えます。クラッシュ・強制終了時には作業データが残る場合があります。不要な `%TEMP%\MDV` と当該アプリの `%TEMP%\.net` サブフォルダは、すべてのMDVを終了した状態で削除できます。次の起動時に再生成します。

起動ごとに新しいWebView2プロファイルを使うため、プレビューのCookieなどは持ち越しません。描画モード・テーマ等はINIから復元します。配布版はEXEに内蔵したFixed Version Runtimeを指定して起動し、端末にインストールされたWebView2の有無には依存しません。

## レジストリの範囲

MDVはレジストリを使った設定保存、ランタイムのインストール・登録、ファイル関連付けの登録を行いません。INIは.NETのファイル操作で読み書きし、WindowsのINI互換APIによるレジストリへの転送も使いません。ファイルダイアログからWindowsの「最近使った項目」への追加も無効にしています。

ただし、Windows、WPF、WebView2が内部で行うレジストリ参照・OSによる実行履歴などの記録まで抑止するものではありません。**プロセスとOS全体について、レジストリアクセスが一切ないことを保証する仕様ではありません。** 通常のポータブルアプリとして、ユーザー設定と起動に必要な依存関係を持ち運べる構成です。

## 更新・ライセンス

更新時はアプリを終了してEXEを置き換え、INIを残してください。同梱のFixed Version Runtimeは自動更新されないため、ランタイムを更新した配布版EXEへの置き換えが必要です。ビルド時の既定バージョン、取得元、SHA-256は `scripts/webview2-runtime.json` で管理しています。

「ヘルプ → 同梱ライセンス」からアプリ・主要依存ライブラリのライセンスを確認できます。展開済み資材には説明書とWebView2パッケージ内の追加ライセンスも含まれます。

設計の根拠: Microsoftの[.NET単一ファイル配布](https://learn.microsoft.com/en-us/dotnet/core/deploying/single-file/overview)と[WebView2のFixed Version配布](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)。
